# PoshanEye - Computer Vision Feature Acquisition

This module handles computer vision tasks for the PoshanEye project.

## Directory Structure

- **data/sample_images/**: Contains sample images for testing and development
- **outputs/json/**: JSON output files from processing
- **outputs/csv/**: CSV output files from processing

## Modules

- **face_detection.py**: Detects faces in images
- **extract_landmarks.py**: Extracts facial landmarks
- **process_dataset.py**: Processes image datasets

## Setup

Install dependencies:
